- **[Contact-GraspNet: Efficient 6-DoF Grasp Generation in Cluttered Scenes](https://arxiv.org/abs/2103.14127)** (2021) — Contact-GraspNet — predicts 6-DoF parallel-jaw grasps for a whole cluttered scene from one depth view by treating observed points as grasp contacts, which shrinks the problem to 4 DoF per point. · [code](https://github.com/NVlabs/contact_graspnet)
- **[Transporter Networks: Rearranging the Visual World for Robotic Manipulation](https://arxiv.org/abs/2010.14406)** (2020) — Transporter Nets — pick-and-place as spatial matching of deep features cropped around the pick point; very sample-efficient on rearrangement tasks, released with the Ravens benchmark. · [code](https://github.com/google-research/ravens)
- **[Solving Rubik's Cube with a Robot Hand](https://arxiv.org/abs/1910.07113)** (2019) — Automatic domain randomization lets a sim-trained hand policy manipulate a Rubik's cube on real hardware.
- **[Learning Dexterous In-Hand Manipulation](https://arxiv.org/abs/1808.00177)** (2018) — A Shadow Hand reorients a cube using RL trained purely in randomized simulation — a sim-to-real milestone.
