- ⭐⭐⭐ **[cuRobo: Parallelized Collision-Free Minimum-Jerk Robot Motion Generation](https://arxiv.org/abs/2310.17274)** (2023) — GPU-parallel motion generation for arms — many trajectory optimizations run at once, giving collision-free, smooth plans in milliseconds. · [code](https://github.com/NVlabs/curobo)
- ⭐ **[cuRoboV2: Dynamics-Aware Motion Generation with Depth-Fused Distance Fields for High-DoF Robots](https://arxiv.org/abs/2603.05493)** (2026) — cuRoboV2 adds torque-aware B-spline trajectory optimization and GPU-native TSDF/ESDF perception for high-DoF robots. · [code](https://github.com/NVlabs/curobo)
- ⭐ **[PyRoki: A Modular Toolkit for Robot Kinematic Optimization](https://arxiv.org/abs/2505.03728)** (2025) — PyRoki: a modular, cross-platform kinematic optimization toolkit that runs natively on CPU, GPU and TPU. · [code](https://github.com/chungmin99/pyroki) · [project](https://pyroki-toolkit.github.io)
- ⭐ **[Planning with Diffusion for Flexible Behavior Synthesis](https://arxiv.org/abs/2205.09991)** (2022) — Diffuser — treats planning as denoising whole trajectories, so goals and rewards can steer sampling; an early link between diffusion and control. · [code](https://github.com/jannerm/diffuser)
- ⭐ **[Predictive Sampling: Real-time Behaviour Synthesis with MuJoCo](https://arxiv.org/abs/2212.00541)** (2022) — Introduces MuJoCo MPC (MJPC), an interactive tool for real-time predictive control in MuJoCo, and shows that a simple sampling-based planner is a strong baseline for contact-rich behaviours. · [code](https://github.com/google-deepmind/mujoco_mpc)
- ⭐ **[legged_control](https://github.com/qiayuanl/legged_control)** (2022) — Open-source NMPC + whole-body control + state-estimation stack for quadrupeds built on OCS2 and ros-control, with a sim-to-real path; a popular starting point for model-based legged control.
- ⭐ **[Jerk-limited Real-time Trajectory Generation with Arbitrary Target States](https://arxiv.org/abs/2105.04830)** (2021) — Ruckig — open-source C++/Python library for time-optimal, jerk-limited online trajectories to any target position, velocity and acceleration; a common drop-in for smooth arm motion on real controllers. · [code](https://github.com/pantor/ruckig)
- ⭐ **[OCS2: Optimal Control for Switched Systems](https://github.com/leggedrobotics/ocs2)** (2021) — C++ toolbox for nonlinear MPC on switched systems (SLQ, DDP, SQP) with robot examples for legged robots and mobile manipulators; the base of many open-source legged MPC + whole-body control stacks.
- ⭐ **[OSQP: An Operator Splitting Solver for Quadratic Programs](https://arxiv.org/abs/1711.08013)** (2020) — A fast, robust ADMM-based QP solver with warm starting and embedded C code generation; widely used inside MPC and whole-body controllers. · [code](https://github.com/osqp/osqp)
- ⭐ **[Crocoddyl: An Efficient and Versatile Framework for Multi-Contact Optimal Control](https://arxiv.org/abs/1909.04947)** (2019) — An open-source DDP-based solver for contact-rich trajectory optimization, widely used for legged and humanoid motion generation and MPC. · [code](https://github.com/loco-3d/crocoddyl)
- ⭐ **[MoveIt 2](https://moveit.ai/)** (2019) — The ROS 2 manipulation framework - motion planning, inverse kinematics, collision checking and real-time servoing for robot arms. · [code](https://github.com/moveit/moveit2)
- ⭐ **[Pinocchio](https://github.com/stack-of-tasks/pinocchio)** (2019) — Fast C++/Python rigid-body dynamics library with analytical derivatives; a common backbone for kinematics, optimal control (e.g. Crocoddyl) and legged/humanoid control stacks.
- ⭐ **[acados: a modular open-source framework for fast embedded optimal control](https://arxiv.org/abs/1910.13753)** (2019) — Fast nonlinear MPC and estimation solvers with Python/MATLAB interfaces that generate C code for embedded targets. · [code](https://github.com/acados/acados)
- ⭐ **[Dynamic Locomotion in the MIT Cheetah 3 Through Convex Model-Predictive Control](https://github.com/mit-biomimetics/Cheetah-Software)** (2018) — Convex MPC for quadrupeds — simplified rigid-body dynamics turn ground-reaction-force planning into a small QP solved in real time; the classic model-based baseline behind many open-source quadruped controllers.
- ⭐ **[Drake](https://drake.mit.edu/)** (2014) — Model-based toolbox for robotics - multibody dynamics with contact simulation, mathematical programming and trajectory optimization; used in the MIT manipulation and underactuated courses. · [code](https://github.com/RobotLocomotion/drake)
- ⭐ **[OMPL: The Open Motion Planning Library](https://ompl.kavrakilab.org/)** (2012) — The standard library of sampling-based motion planners (RRT, RRT-Connect, PRM, RRT* and many more); the default planning backend of MoveIt. · [code](https://github.com/ompl/ompl)
- **[$λ$-Reachability: Geometric-Horizon Safety Bellman Equations for Humanoid Safety](https://arxiv.org/abs/2606.16022)** (2026) — λ-Reachability learns Hamilton-Jacobi safety values with a TD(λ)-like multi-step estimator with a random horizon, proven to be a contraction; better safe-set estimates on simulated and real humanoids.
- **[A generalist policy for muscle-driven control across individual musculoskeletal models](https://arxiv.org/abs/2610.36535)** (2026) — MyoAcross trains one morphology-conditioned policy that tracks reference motions on unseen individual musculoskeletal models without fine-tuning. Reports 99.24% completion on 31 held-out models and 22.6% lower error. · [project](https://woodater-thu.github.io/MyoAcross/)
- **[BarrierFormer: Transformer-Guided Predictive Barrier Enforcement for Safe Robot Control](https://arxiv.org/abs/2609.23896)** (2026) — A causal transformer predicts a rollout (in place of a model) and a residual fix to a nominal controller; a barrier critic scores CBF violations along the rollout, so safety looks ahead like MPC.
- **[CusADi2: Latency-Optimized Batch Computation of Robot Kinematics, Jacobians, and Hessians on the GPU](https://arxiv.org/abs/2610.25476)** (2026) — Evaluates batches of kinematics, Jacobians and Hessians on the GPU with low wall-clock latency, targeting online sampling- and gradient-based trajectory optimization. · [code](https://github.com/johnviljoen/cusadi2)
- **[Exploring the Intrinsic Geometry of Diffusion Models with Constrained Inverse Kinematics](https://arxiv.org/abs/2606.26408)** (2026) — Uses constrained IK, where solution manifolds are known exactly, to test what geometry diffusion models learn. On UR5 and Franka the intrinsic dimension read from the score matches the analytic degrees of freedom. · [code](https://github.com/utiasSTARS/ConstraintIK) · [project](https://papers.starslab.ca/diffusion-ik-geometry/)
- **[Gradient-Free Neural Hamilton-Jacobi Reachability for Scalable Safety-Critical Control](https://arxiv.org/abs/2609.14087)** (2026) — Discrete-time neural HJ reachability without PDE gradients: bang-bang structure and gradient-free value probes give teacher actions, turning adversarial actor learning supervised; a windowed curriculum adds stability.
- **[Keeping Contact: Task-Adaptive Friction Margins for Bimanual Non-Prehensile Manipulation](https://arxiv.org/abs/2610.36961)** (2026) — Signed friction distance as a task-adaptive slip margin for bimanual tilting about a pivot; a sequence of SOCPs gives optimal contact forces. Real tests show adaptive margins beat fixed or no margins. · [project](https://keeping-contact.github.io/)
- **[Koopman DCM: Unstable Eigenfunctions as Data-driven Representations for Legged Balancing](https://arxiv.org/abs/2607.18760)** (2026) — Recasts divergent components of motion as unstable Koopman eigenfunctions learned from about an hour of real biped data; they improve walking tracking and give viability constraints for MPC.
- **[LEMCA: LLM-Guided Synthesis of Efficient Mode-Switching Control Architectures](https://arxiv.org/abs/2609.21319)** (2026) — LLM-driven evolutionary search over mode-switching controllers written as programs, so cheap modes run in easy task phases. Reports designs beyond the Pareto front of one-size-fits-all controllers. · [project](https://lemca-robotics.github.io/)
- **[Learning Unions of Convex Sets via Invertible Latent Decomposition for Path Planning](https://arxiv.org/abs/2606.12027)** (2026) — Learns an invertible map plus convex polytopes in its latent space, so convex-set planners work in high-DoF spaces and paths decode back feasible. Tested from 2D to 14-DoF; no false positives after refinement.
- **[M$^3$P-R1: Reinforcement Learning for Large Language Model Guided Multi-Modal Motion Planning via MIP Code Generation](https://arxiv.org/abs/2609.18669)** (2026) — Fine-tunes an LLM with solver-based RL rewards to write executable mixed-integer programs for multi-modal motion planning (e.g. walk, then grasp), instead of answering directly.
- **[MPC-Injection: Biasing Off-Policy Locomotion RL Toward Controller-Induced Behavior Basins](https://arxiv.org/abs/2606.26392)** (2026) — MPC-Injection steers off-policy RL toward a usable gait by inserting MPC-generated transitions into training, with no reward shaping or discriminator; Go2 sim-to-real, and a barrel roll pure RL misses.
- **[On the Limits of Sampling-Based Reachability: Geometry, Dynamics, and Sample Complexity](https://arxiv.org/abs/2607.18606)** (2026) — Theory: gives conditions under which sampled reachable sets are accurate in Hausdorff distance, and shows the sample need grows exponentially in both state dimension and horizon, with a matching lower bound.
- **[Optimal Control with Learned Critics under Unmodeled State Dependencies](https://arxiv.org/abs/2610.05359)** (2026) — Adds a residual dynamics network and a learned Q critic to iLQR MPC, with a GPU batched iLQR that solves thousands of problems in parallel, for model-based RL when contacts are poorly modeled.
- **[PAKT: Physically-Aligned Kinesthetic Teaching for Reinforcement Learning](https://arxiv.org/abs/2609.25630)** (2026) — Kinesthetic teaching for real-world RL that keeps human guidance within the policy's kinematic limits, plus an impedance control stack. Reports 23–48% shorter cycle time vs HIL-SERL on industrial insertion. · [project](https://pakt-website.github.io/pakt-website)
- **[PRISM: Polynomial Representations for Interaction-Structured Motor Control](https://arxiv.org/abs/2607.23473)** (2026) — Replaces a policy MLP's first layer with learned multiplicative (bilinear) features, plug-and-play for RL and imitation. Reports humanoid survival up from 51.0% to 92.5%, holding under friction and payload shifts. · [code](https://github.com/lsh3163/prism) · [project](https://lsh3163.github.io/prism/)
- **[PolicyIK: High-Precision Inverse Kinematics for Robot Arms with Reinforcement Learning](https://arxiv.org/abs/2611.05372)** (2026) — Learned goal-conditioned inverse kinematics that can hold the offset a position controller needs at rest; reports errors within 1 mm and 0.2° on 93.5% of held-out simulated tasks and training directly on a real arm. · [code](https://github.com/Tinaliu0123/PolicyIK)
- **[PrismPlan: A Shared GPU Substrate for Motion Planning Across Paradigms](https://arxiv.org/abs/2610.23884)** (2026) — Builds batched GPU collision checking and forward kinematics once and runs sampling, search and optimization planners on top, so the three paradigms can be compared fairly. · [code](https://github.com/XiaoyubotMotionTeam/PrismPlan)
- **[RAM: Reachability Across Morphologies](https://arxiv.org/abs/2606.09108)** (2026) — CoRL 2026 Spotlight. A morphology-conditioned implicit neural model of pose reachability, differentiable, self-collision aware and able to generalize to unseen morphologies. · [code](https://github.com/TimWalter/ram) · [project](https://timwalter.github.io/ram)
- **[Safe Streaming Flow Planning by Aligning Sampling Dynamics with Execution Dynamics](https://arxiv.org/abs/2610.03132)** (2026) — Flow-matching planner whose sampling steps follow the execution dynamics, so safety (high-order CBFs) is enforced only on the executed step. Lower latency and better safety on navigation, racing and locomotion. · [code](https://github.com/Jang-seunghwan/SafeStreamingFlowPlanning) · [project](https://jang-seunghwan.github.io/SafeStreamingFlowPlanning/)
- **[Scalable Deep Unfolding of Conic Optimizers](https://arxiv.org/abs/2606.13825)** (2026) — Makes deep unfolding work for large conic solvers via matrix-free implicit differentiation and a stable PSD-projection gradient; reports up to 50× speedups on SDP-based planning.
- **[Sub-Millisecond Reflexes for Continuous Physical Human-Robot Interaction](https://arxiv.org/abs/2610.21913)** (2026) — An open-source ROS 2 multimode controller that switches control modes and triggers safety reflexes in under a millisecond, without stopping the task; shown on a Franka arm. · [code](https://github.com/RoboRef/franka_reflex_engine)
- **[TAM: Torque Adaptation Module for Robust Motion Transfer in Manipulation](https://arxiv.org/abs/2606.06218)** (2026) — CoRL 2026 Spotlight. A module for contact-rich motion transfer across sim-to-real gaps, payloads and robot instances, as an alternative to domain randomization or system ID. · [code](https://github.com/Dongwon-Son/TAM) · [project](https://dongwon-son.github.io/tam-project-page/)
- **[TDC: Sim-to-Real Transferable Directional Compliance for Contact-Rich Manipulation](https://arxiv.org/abs/2602.14174)** (2026) — Splits force regulation into a direction part learned in sim (task frame and control-mode outputs of a VLA-based policy) and a magnitude part set by hand in an admittance controller. Sim data only; four real tasks. · [project](https://yifei-y.github.io/project-pages/TDC/)
- **[VIGOR-MPC: Vision-Guided Objective Regulation MPC](https://arxiv.org/abs/2610.20333)** (2026) — VIGOR-MPC distills a privileged long-horizon MPC into a short-horizon MPC whose cost weights are inferred online from noisy vision; in vision-based racing it nears the teacher's lap times with 90%+ less compute per step.
- **[VertexCBF: Improving Neural Control Barrier Functions via Vertex-Restricted Control Search](https://arxiv.org/abs/2609.12831)** (2026) — Learns neural CBFs from an HJ value approximation; with control-affine dynamics and polytope inputs the optimum is at a vertex, so GPU vertex tree search makes labels. 15 systems + a robot among pedestrians.
- **[When Should a Robot Replan? Regret-Guided Update Scheduling in Time-Varying MDPs](https://arxiv.org/abs/2606.16972)** (2026) — With a limited budget for re-estimation and replanning under drifting dynamics, a dynamic-regret bound gives an online rule for when to update. Tested on simulated rover slip and a Crazyflie quadrotor.
- **[Motions in Microseconds via Vectorized Sampling-Based Planning](https://arxiv.org/abs/2309.14545)** (2023) — VAMP — vectorizes collision checking with CPU SIMD so sampling-based planners like RRT-Connect solve arm motion-planning queries in microseconds to milliseconds, no GPU needed. · [code](https://github.com/KavrakiLab/vamp)
- **[Motion Policy Networks](https://arxiv.org/abs/2210.12209)** (2022) — A neural policy trained on millions of planner-generated trajectories that moves an arm to goals straight from point clouds. · [code](https://github.com/NVlabs/motion-policy-networks)
- **[Safe Learning in Robotics: From Learning-Based Control to Safe Reinforcement Learning](https://arxiv.org/abs/2108.06266)** (2021) — Survey connecting control-theory and RL views of safety, from learned dynamics with guarantees to constrained RL and safety filters.
- **[safe-control-gym: a Unified Benchmark Suite for Safe Learning-based Control and Reinforcement Learning in Robotics](https://arxiv.org/abs/2109.06325)** (2021) — Gym-style benchmark with cart-pole and quadrotor tasks, constraints and disturbances for comparing safe control and safe RL methods. · [code](https://github.com/utiasDSL/safe-control-gym)
- **[Control Barrier Functions: Theory and Applications](https://arxiv.org/abs/1903.11199)** (2019) — Tutorial on control barrier functions — the standard way to wrap any controller in a minimal-change filter that keeps the system safe.
- **[Riemannian Motion Policies](https://arxiv.org/abs/1801.02854)** (2018) — RMPs — describe each behaviour (reach, avoid obstacles, joint limits) as an acceleration policy plus a Riemannian metric, then combine them geometrically; the basis of later RMPflow and geometric fabrics controllers.
- **[Hamilton-Jacobi Reachability: A Brief Overview and Recent Advances](https://arxiv.org/abs/1709.07523)** (2017) — Short tutorial on Hamilton-Jacobi reachability — computing the set of states from which a system can be kept safe under worst-case disturbances, and the tricks used to scale it up.
