- ⭐⭐⭐ **[LEAP Hand: Low-Cost, Efficient, and Anthropomorphic Hand for Robot Learning](https://arxiv.org/abs/2309.06440)** (2023) — A 16-DoF dexterous hand buildable for about $2,000 from off-the-shelf parts. · [code](https://github.com/leap-hand/LEAP_Hand_API) · [project](https://leaphand.com/)
- ⭐⭐ **[Pixel: A Co-Designed Full-Stack Robot System for Learning General-Purpose Mobile Manipulation](https://arxiv.org/abs/2611.03648)** (2026) — Hardware, data and learning designed together: a low-cost wheeled humanoid with compliant grippers, teleoperation and robot-free human data collection, one whole-body controller and a shared policy pipeline. · [project](https://pixel-robot.com/pixel)
- ⭐ **[Demonstrating Berkeley Humanoid Lite: An Open-source, Accessible, and Customizable 3D-printed Humanoid Robot](https://arxiv.org/abs/2504.17249)** (2025) — Open-source humanoid with 3D-printed modular gearboxes, buildable for under US$5,000; hardware designs, embedded code and training code are released. · [code](https://github.com/HybridRobotics/Berkeley-Humanoid-Lite) · [project](https://lite.berkeley-humanoid.org)
- ⭐ **[OpenArm](https://github.com/enactic/openarm)** (2025) — Fully open-source 7-DoF humanoid arm for contact-rich work — CAD, electronics, firmware, ROS 2 and MuJoCo/Genesis models, plus leader–follower force-feedback teleop and gravity compensation. · [project](https://openarm.dev)
- ⭐ **[ALOHA 2: An Enhanced Low-Cost Hardware for Bimanual Teleoperation](https://arxiv.org/abs/2405.02292)** (2024) — Upgraded ALOHA bimanual rig (stronger grippers, gravity compensation, sturdier frame) with open hardware designs and a MuJoCo model for simulation. · [code](https://github.com/tonyzhaozh/aloha) · [project](https://aloha-2.github.io/)
- ⭐ **[Open-TeleVision: Teleoperation with Immersive Active Visual Feedback](https://arxiv.org/abs/2407.01512)** (2024) — VR teleoperation with an actively steered stereo camera, used to collect humanoid manipulation data. · [code](https://github.com/OpenTeleVision/TeleVision)
- ⭐ **[SO-ARM100 / SO-101](https://github.com/TheRobotStudio/SO-ARM100)** (2024) — An open 3D-printed 6-DoF arm (leader + follower) costing roughly $100–200 per arm; the default LeRobot starter kit.
- ⭐ **[An Open Torque-Controlled Modular Robot Architecture for Legged Locomotion Research](https://arxiv.org/abs/1910.00093)** (2019) — The open-source Solo quadruped and its modular torque-controlled actuators, built from off-the-shelf and 3D-printed parts so labs can reproduce a dynamic legged robot. · [code](https://github.com/open-dynamic-robot-initiative/open_robot_actuator_hardware)
- **[Belt-Finger: An Affordable Soft Belt-Driven Gripper for Dexterous In-Hand Manipulation](https://arxiv.org/abs/2606.20193)** (2026) — A cheap drop-in finger module for parallel grippers: two soft belts keep normal open/close and add in-hand translation, pitch and roll; used with MPC, a light 10-DoF teleop interface and learned policies.
- **[DexPort: A Hand-Held Skill Interface for Dexterous Hand Data Collection](https://arxiv.org/abs/2610.32969)** (2026) — A portable hand-held rig for collecting demonstrations with a high-DoF robot hand, using the same hand hardware for collection and deployment, so there is no retargeting from human hands and no full robot setup needed. · [code](https://github.com/amazon-far/dexport) · [project](https://amberxie88.github.io/dexport/)
- **[EgoThumb: A Vision-Driven Supernumerary Robotic Thumb for Autonomous Grasp and Holding Assistance](https://arxiv.org/abs/2610.37582)** (2026) — Open-source wearable extra thumb: a tendon-driven finger with motors moved to the forearm; an imitation policy maps palm-camera images to joint positions, inferring intent without explicit triggers. · [code](https://github.com/JayeFu/ego_thumb_firmware) · [project](https://ego-thumb.github.io)
- **[Hardware-as-Regularization: Enhancing Data Consistency in Imitation Learning via an Adjustable Passive Compliant Leader Arm](https://arxiv.org/abs/2610.22977)** (2026) — Adds a cheap clutch and 3D-printed spring to each joint of a passive leader arm so redundant joints return to a neutral pose, making demos more consistent; block stacking success 73.3% vs 36.7%.
- **[KlaskTron: An Open-Source Platform for Physical Adversarial Multi-Agent RL](https://arxiv.org/abs/2611.03138)** (2026) — A desktop testbed under $2,500 for adversarial multi-agent RL, built around the tabletop game KLASK: open CAD and BOM, an Isaac Lab digital twin, and a sim-to-real baseline with a learned actuator model. · [code](https://github.com/IDSCETHZurich/klask_rl) · [project](https://idscethzurich.github.io/klask_hardware)
- **[LocoPilot: Single-Operator Bilateral Teleoperation for Loco-Manipulation Policy Learning](https://arxiv.org/abs/2610.27998)** (2026) — One operator drives a Unitree Go2 + Piper arm with a leader arm and two handheld controllers, with sensorless force feedback; records a unified 11-D action reused at deployment (shown by fine-tuning MolmoAct2). · [code](https://github.com/iit-DLSLab/LocoPilot)
- **[Low-Cost Mobile Bimanual Manipulation for Long-Horizon Toilet Cleaning](https://arxiv.org/abs/2611.15381)** (2026) — Two SO-101 arms on a TurtleBot 4 with a LeRobot-ROS 2 stack; 250 demos of toilet cleaning compare π0, π0.5, SmolVLA and GR00T on the same robot. π0 is best (60% strict, 90% with light help). · [project](https://so101-turtlebot4.github.io/mobile-bimanual-cleaning/)
- **[MABEL: An Open Anthropomorphic Mobile Bimanual Platform for Teleoperation and Learning](https://arxiv.org/abs/2611.04083)** (2026) — An open-source 56-DOF mobile bimanual robot with 7-DOF arms and 17-DOF hands for about US$8.1k in parts, with Apple Vision Pro teleoperation and a demonstrated imitation learning pipeline. · [project](https://robotmabel.github.io/website/)
- **[OpenJaws: An Open Hardware UMI Framework with Stereo Localization for Generalist Manipulation](https://arxiv.org/abs/2610.36598)** (2026) — Fully open UMI-style handheld gripper with a low-cost stereo camera for metric, low-drift trajectories, plus UMI-Loc-Bench-v1 for localization accuracy; hardware, software and data under a permissive license. · [project](https://open-jaws.github.io/)
- **[PHD-Hand: A Printable Humanoid Dexterous Hand with Linkage-Driven 3-DOA Digits](https://arxiv.org/abs/2610.29030)** (2026) — Fully linkage-driven humanoid hand with 3 actuated DoF per finger; a flexure hinge and spring-steel drive rods replace many tiny parts, so it prints on a budget 3D printer at near human-hand size.
- **[PanoVine: Whole-Body Visuomotor Control for Soft Growing Vine Robot](https://arxiv.org/abs/2606.22923)** (2026) — First autonomous vine (soft growing) robot: 19 cameras along its body feed an end-to-end visuomotor policy learned from demos, which steers through branches, up slopes and into confined spaces. · [code](https://github.com/xxm19/panovine) · [project](https://panovine-bot.github.io)
- **[RAIPAL: A Powerful and Agile Humanoid Arm for Human Tasks](https://arxiv.org/abs/2611.04334)** (2026) — A humanoid arm whose force, speed and endurance targets come from human upper-limb measurements; reports a 20 kg peak payload (2.25x its own mass) and 20.6 m/s endpoint speed.
- **[RUMI: A Robotiq-Matched Universal Manipulation Interface for Robot Learning with Augmented Reality and Haptic Feedback](https://arxiv.org/abs/2611.15802)** (2026) — A UMI-style handheld gripper matched to the Robotiq 2F-85's mechanics, with swappable fingertip sensors, live AR feasibility feedback in a VR headset and haptics. AR cut joint-limit violations from 16/50 to 3/50.
- **[RealDexUMI: A Wearable Universal Manipulation Interface for Dexterous Robot Learning](https://arxiv.org/abs/2606.06033)** (2026) — Wearable dexterous UMI: a shared end-effector module (light hand, in-hand camera, fingertip touch) driven by an isomorphic glove, so collected and deployed observations and actions match. Eight real tasks.
- **[SEED-UMI: Sharing the Exoskeleton between human and robot for onE-to-one Dexterous demonstration](https://arxiv.org/abs/2609.11753)** (2026) — Human and robot wear the same hand exoskeleton, so encoders and wrist cameras match between collection and rollout; retargeting becomes paired supervision. 3.0x faster collection, 70.0% success on five tasks.
- **[SPOT: Spatial Perception-Oriented Long-Horizon Humanoid Teleoperation](https://arxiv.org/abs/2609.07933)** (2026) — VR humanoid teleoperation for long tasks: a robot-mounted binocular fisheye, wide stereo display, head-decoupled free-looking and stabilization keep the operator aware of the surroundings.
- **[Shape Your Body: Value Gradients for Multi-Embodiment Robot Design](https://arxiv.org/abs/2606.00702)** (2026) — Reuses a frozen multi-robot value function as a differentiable surrogate for robot design, avoiding a new co-design RL loop per robot; handles over 1100 design parameters.
- **[SuperSuit: An Isomorphic Bimodal Interface for Scalable Mobile Manipulation](https://arxiv.org/abs/2603.06280)** (2026) — One wearable both teleoperates a wheeled bimanual robot and records robot-free demos; arms are mechanically aligned, so no IK or retargeting. With a 10-episode robot-grounded seed, 100 robot-free episodes suffice.
- **[SwapBot: Tool-Centric Robot Manipulation via Interchangeable End-Effectors and Tactile Sensing](https://arxiv.org/abs/2610.40646)** (2026) — Instead of one universal gripper: a fixed robot-side coupling plus cheap tool-side adapters with tactile sensors turn household tools into swappable end effectors; imitation policies cook tofu and flip meat. · [project](https://personalrobotics.github.io/SwapBot)
- **[Transformer Transformer: A Unified Model for Motion-Conditioned Robot Co-design](https://arxiv.org/abs/2607.25798)** (2026) — Diffusion transformer over a shared tokenization of robot bodies, states and actions that generates robot designs to track target motions. A fabricated optimised ALOHA design cut tracking error by over 70%. · [code](https://github.com/real-stanford/transformer-transformer) · [project](https://transformer-transformer.github.io)
- **[UMI-Live for In-The-Wild Bimanual Robotics Data Collection](https://arxiv.org/abs/2610.39385)** (2026) — Open-source bimanual UMI with camera, LiDAR-inertial sensing, compute and power on board: no external tracking or calibration; parallel SLAM outputs training-ready data. Releases 40 h of data and hardware files. · [code](https://github.com/AfterQuery-Research/umi-live) · [project](https://umi-live.github.io/)
- **[Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback](https://arxiv.org/abs/2606.14218)** (2026) — Low-cost upper-limb exoskeleton that records whole-arm poses and joint torques with real-time haptic torque feedback; retargets to OpenArm, Franka and xArm for learning compliant whole-body policies. · [code](https://github.com/inclusionAI/Universal-Manipulation-Exoskeleton) · [project](https://ume-exo.github.io)
- **[YOCO: You Only Calibrate Once! Fast Mocap Calibration for Dexterous Teleoperation](https://arxiv.org/abs/2610.11657)** (2026) — Few-shot calibration of biased mocap gloves or hand trackers: a HyperNet reads a few paired poses and predicts LoRA updates for a frozen MANO estimator, with no per-user fine-tuning.
- **[AirExo-2: Scaling up Generalizable Robotic Imitation Learning with Low-Cost Exoskeletons](https://arxiv.org/abs/2503.03081)** (2025) — Exoskeleton demos are converted into pseudo-robot demonstrations; the paper reports its RISE-2 policy trained on them alone, with no robot data, performs comparably to one trained on teleoperated robot data. · [code](https://github.com/AirExo/AirExo-2)
- **[BEHAVIOR Robot Suite: Streamlining Real-World Whole-Body Manipulation for Everyday Household Activities](https://arxiv.org/abs/2503.05652)** (2025) — A whole-body teleoperation interface plus a learning method for a wheeled bimanual robot doing long household tasks that need reach, balance and navigation. · [project](https://behavior-robot-suite.github.io/)
- **[DOGlove: Dexterous Manipulation with a Low-Cost Open-Source Haptic Force Feedback Glove](https://arxiv.org/abs/2502.07730)** (2025) — An open-source teleoperation glove buildable in hours for under $600, with 21-DoF hand capture, 5-DoF cable-driven force feedback and fingertip haptics; reports the feedback matters for contact-rich tasks without vision. · [code](https://github.com/TEA-Lab/DOGlove) · [project](https://do-glove.github.io/)
- **[DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation](https://arxiv.org/abs/2505.21864)** (2025) — DexUMI — an exoskeleton matched to the robot hand's fingertip workspace, plus inpainting that swaps the human hand for the robot's; reports 86% average success (Inspire, XHand) and ~3.2× faster collection than teleop. · [code](https://github.com/real-stanford/DexUMI) · [project](https://dex-umi.github.io/)
- **[HOMIE: Humanoid Loco-Manipulation with Isomorphic Exoskeleton Cockpit](https://arxiv.org/abs/2502.13013)** (2025) — Open-source whole-body humanoid teleoperation — an arm exoskeleton plus motion-sensing gloves, with a foot pedal steering an RL walking controller; the cockpit hardware costs about US$500. · [code](https://github.com/InternRobotics/OpenHomie) · [project](https://homietele.github.io/)
- **[MEVITA: Open-Source Bipedal Robot Assembled from E-Commerce Components via Sheet Metal Welding](https://arxiv.org/abs/2508.17684)** (2025) — Open-source biped built from e-commerce parts by sheet-metal welding, avoiding the size and fragility limits of 3D-printed designs. · [code](https://github.com/haraduka/mevita) · [project](https://haraduka.github.io/mevita-hardware)
- **[ORCA: An Open-Source, Reliable, Cost-Effective, Anthropomorphic Robotic Hand for Uninterrupted Dexterous Task Learning](https://arxiv.org/abs/2504.04259)** (2025) — A 3D-printable, 17-DoF tendon-driven hand with fingertip tactile sensing, under CHF 2,000 in materials; design files and code are open, and the paper reports long continuous runs for teleoperation and learning. · [project](https://www.orcahand.com)
- **[RUKA: Rethinking the Design of Humanoid Hands with Learning](https://arxiv.org/abs/2504.13165)** (2025) — A human-sized, tendon-driven hand (5 fingers, 15 underactuated DoF) from 3D-printed and off-the-shelf parts; joint-to-actuator control is learned from MANUS-glove mocap data instead of hand-modelled. · [code](https://github.com/ruka-hand/RUKA) · [project](https://ruka-hand.github.io/)
- **[ToddlerBot: Open-Source ML-Compatible Humanoid Platform for Loco-Manipulation](https://arxiv.org/abs/2502.00893)** (2025) — A small, 3D-printed open-source humanoid with a matching simulation model, built so that ML policies and teleoperated data transfer to the real robot. · [code](https://github.com/hshi74/toddlerbot) · [project](https://toddlerbot.github.io/)
- **[ACE: A Cross-Platform Visual-Exoskeletons System for Low-Cost Dexterous Teleoperation](https://arxiv.org/abs/2408.11805)** (2024) — ACE — a 3D-printed bimanual exoskeleton for wrist pose plus hand-facing webcams for finger pose (about $600); one setup teleoperates arm-hand systems, humanoids and quadruped-mounted arms. · [code](https://github.com/ACETeleop/ACETeleop) · [project](https://ace-teleop.github.io/)
- **[Berkeley Humanoid: A Research Platform for Learning-based Control](https://arxiv.org/abs/2407.21781)** (2024) — A mid-size, low-cost humanoid designed for easy sim-to-real transfer of RL locomotion.
- **[Bimanual Dexterity for Complex Tasks](https://arxiv.org/abs/2411.13677)** (2024) — Bidex — a portable, low-latency bimanual dexterous teleop rig (mocap gloves + teacher arms) for 50+ DoF robots; reports better data, collected faster, than Vision Pro or SteamVR teleop. · [project](https://bidex-teleop.github.io/)
- **[Bunny-VisionPro: Real-Time Bimanual Dexterous Teleoperation for Imitation Learning](https://arxiv.org/abs/2407.03162)** (2024) — Apple Vision Pro teleoperation of two dexterous robot hands with real-time retargeting, collision and singularity avoidance, and low-cost vibration haptics for the operator. · [code](https://github.com/Dingry/BunnyVisionPro)
- **[Learning Visuotactile Skills with Two Multifingered Hands](https://arxiv.org/abs/2404.16823)** (2024) — HATO — bimanual setup from two UR5e arms and repurposed prosthetic hands with fingertip touch sensors, VR teleop for data collection, and visuotactile policies for tasks like pouring and handovers. · [code](https://github.com/ToruOwO/hato) · [project](https://toruowo.github.io/hato/)
- **[TeleMoMa: A Modular and Versatile Teleoperation System for Mobile Manipulation](https://arxiv.org/abs/2403.07869)** (2024) — One modular teleop interface that mixes RGB-D body tracking, VR controllers, keyboard and joystick for whole-body mobile manipulators (Tiago++, HSR, Fetch), in sim and real. · [code](https://github.com/UT-Austin-RobIn/telemoma) · [project](https://robin-lab.cs.utexas.edu/telemoma-web/)
- **[The Duke Humanoid: Design and Control For Energy Efficient Bipedal Locomotion Using Passive Dynamics](https://arxiv.org/abs/2409.19795)** (2024) — Open-source 10-DoF humanoid for locomotion research; an RL policy using passive dynamics cuts cost of transport by up to 50% in sim and 31% on hardware. · [code](https://github.com/generalroboticslab/dukeHumanoidHardwareControl)
- **[TidyBot++: An Open-Source Holonomic Mobile Manipulator for Robot Learning](https://arxiv.org/abs/2412.10447)** (2024) — An inexpensive open-source mobile base with powered casters, so it is fully holonomic; carries arbitrary arms and comes with phone teleoperation for collecting mobile-manipulation demos for imitation learning. · [code](https://github.com/jimmyyhwu/tidybot2)
- **[UMI-on-Legs: Making Manipulation Policies Mobile with Manipulation-Centric Whole-body Controllers](https://arxiv.org/abs/2407.10353)** (2024) — Robot-free UMI gripper demos train the manipulation policy; a sim-trained whole-body controller tracks its end-effector trajectories on a quadruped. Reports >70% success on all tasks and zero-shot reuse of an arm policy. · [code](https://github.com/real-stanford/umi-on-legs)
- **[AirExo: Low-Cost Exoskeletons for Learning Whole-Arm Manipulation in the Wild](https://arxiv.org/abs/2309.14975)** (2023) — A portable dual-arm exoskeleton (about $600 in parts, per the paper) for joint-level teleop and cheap in-the-wild demos; reports few-minute teleop plus wild data rivals much longer teleop-only training. · [code](https://github.com/AirExo/collector)
- **[AnyTeleop: A General Vision-Based Dexterous Robot Arm-Hand Teleoperation System](https://arxiv.org/abs/2307.04577)** (2023) — Camera-only teleoperation for arm + dexterous hand pairs - tracks the operator's hand and retargets it to many different robot hands, in sim or on real hardware.
- **[GELLO: A General, Low-Cost, and Intuitive Teleoperation Framework for Robot Manipulators](https://arxiv.org/abs/2309.13037)** (2023) — 3D-printed kinematic replicas of robot arms for cheap, intuitive joint-space teleoperation. · [code](https://github.com/wuphilipp/gello_software)
