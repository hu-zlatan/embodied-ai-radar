- **[Adapting Video Models for Robot Control via Motion-guided Asymmetric Prediction](https://arxiv.org/abs/2610.36624)** (2026) — MoGAP adds a training-only auxiliary path to world action models that corrupts moving regions more than static ones, focusing visual supervision on motion. - **[Calibrated for Which Policy? Conformal Uncertainty for Fixed World Models Under Intervention](https://arxiv.org/abs/2610.35877)** (2026) — Shows a fixed world model's uncertainty can break when the deployment policy changes; reweights conformal calibration by a learned state-action ratio. Model-based RL that uses a chunk world model as a differentiable training-time evaluator, targeting compounding error, inference latency and BPTT instability. · [code](https://github.com/song-wx/CMPO) · [project](https://song-wx.github.io/cmpo.github.io/)
- **[DeXplicit: Making Physical State Explicit in Dexterous Manipulation World Models](https://arxiv.org/abs/2610.30781)** (2026) — Dexterous-manipulation world model that first predicts object motion and deformation in metric 3D from a hand trajectory, then renders video. - **[DreamX: Video Diffusion Model is a Universal Latent Action Learner](https://arxiv.org/abs/2611.05377)** (2026) — Reuses a pretrained video diffusion model to extract compact latent actions (1,200 to 4 tokens per frame) that act as a shared interface across humans, robots and environments, including zero-shot action transfer. · [code](https://github.com/cvlab-kaist/DreamX) · [project](https://cvlab-kaist.github.io/DreamX/)
- **[GAWM: A Compact Latent World-Action Model for Multi-Task Robot Manipulation](https://arxiv.org/abs/2610.37091)** (2026) — Compact (<100M) world-action model: predicts frozen-DINOv3 tokens at two future horizons and decodes action chunks, with no robot or video pretraining. - **[GreenWAM: A World Foundation Model for Robotics](https://arxiv.org/abs/2610.18774)** (2026) — One world model that is also the policy, across 20 robot families mapped to a shared joint-space action format; reports strong WorldArena, RoboTwin 2.0 and LIBERO-plus results and a one-step distilled humanoid policy. · [code](https://github.com/greenvla/GreenWAM) · [project](https://greenvla.github.io/GreenWAM)
- **[Hierarchical World Models with Implicit Dynamics](https://arxiv.org/abs/2610.42146)** (2026) — ID-WM pairs a high-level model that samples reachable transitions with a low-level world model used as an inverse-dynamics solver. - **[LaWAM: Latent World Action Models for Efficient Dynamics-Aware Robot Policies](https://arxiv.org/abs/2606.15768)** (2026) — World action model without video generation: predicts future features in a vision foundation model's latent space as policy subgoals. Reports 98.6% on LIBERO and up to 24× lower latency than pixel WAMs. · [code](https://github.com/RLinf/LaWAM) · [project](https://rlinf.github.io/LaWAM/)
- **[OSWAM: An Effective World Action Model with One-Step Action Generation](https://arxiv.org/abs/2610.35850)** (2026) — World action model that acts in one diffusion step: 'imagination tokens' replace random-noise initialisation as an action prior. Reports ~3× speedup over direct-policy WAMs, 40 ms latency on an RTX 5090. · [code](https://github.com/PolyU-VCLab/OSWAM) · [project](https://gwenzhang.github.io/OSWAM/)
- **[OpenNWM: A Generalist Navigation World Model with Latent Action Pretraining](https://arxiv.org/abs/2611.01844)** (2026) — Learns latent actions from action-free video, then aligns them with physical motion in post-training. - **[PICA-WAM: Visual Perturbation Invariance via Cross-Appearance Self-Alignment in World Action Models](https://arxiv.org/abs/2610.26813)** (2026) — Auxiliary training task for world action models: an EMA teacher sees the clean frame, the online model sees a perturbed one and aligns its action features.
